# Dot Dash

A maze-chase game that runs in any web browser. Steer the green blob, eat every dot,
and dodge the four robots. Grab a pink orb to scare the robots, then eat them for bonus points.

## How to play

Open `index.html` in a web browser.

- **Move:** arrow keys or WASD (swipe on a phone)
- **Pause:** P
